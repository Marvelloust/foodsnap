# FoodSnap design system

## Visual position

FoodSnap uses a **visual-intelligence product** language rather than generic wellness green, purple AI glow, glassmorphism, paper grids or oversized poster typography.

The UI is deliberately denser inside the application than on the public website.

## Palette

- Deep Ink — `#10191A`
- Porcelain — `#F3F5F1`
- Surface — `#FBFCF8`
- Petrol — `#123D3D`
- Burnt Tomato — `#C94B37`
- Saffron — `#D6A32B`
- Cobalt — `#315B98`
- Success — `#2F6858`

## Type

- UI: Manrope
- Food/display titles: Newsreader
- system/scan metadata: Azeret Mono

Large display type is reserved for the public hero and major food-detail moments. Application headings use compact sizes so information density remains useful.

## Signature UI patterns

### Scan field
A dark, spatial image surface with scan beam, grid field, analysis state and bounding regions.

### Result provenance
Four consistent source labels:

- FoodSnap Found
- FoodSnap Extracted
- FoodSnap Inferred
- FoodSnap Matched

### Visual archive
The Library uses variable-height visual records rather than identical dashboard cards.

### Discovery graph
Food, ingredients, cuisines and recipes appear as connected nodes so exploration feels relational rather than menu-based.

### Cook Mode
Recipes transform into a focused full-screen step interface.

## Motion

Motion is based on scanning, detection, connection and transformation:

- scan beam traversal
- component region focus
- graph relationships
- image/result continuity
- theme transitions
- Cook Mode takeover

`prefers-reduced-motion` removes nonessential animation.
